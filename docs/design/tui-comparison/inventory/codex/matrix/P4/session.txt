• ## JavaScript Event Loop

  1. Run synchronous code on the call stack first.
  2. Queue async callbacks when their work is ready.
  3. When the stack is empty, run microtasks before regular tasks.

  console.log("start");
  setTimeout(() => console.log("timer"), 0);
  Promise.resolve().then(() => console.log("microtask"));
  console.log("end");

  | Part | Purpose |
  |---|---|
  | Call stack | Runs synchronous code |
  | Microtasks | Promise callbacks |
  | Tasks | Timers and events |
