     Understanding the JavaScript Event Loop

     The event loop enables JavaScript's non-blocking I/O model by continuously checking the call stack

     2. Completed async callbacks move from the task queue to the stack
     3. Microtasks (Promises) always run before macrotasks (setTimeout)
