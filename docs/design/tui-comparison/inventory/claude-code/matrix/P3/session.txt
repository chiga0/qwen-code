⏺ Here's a recursive Fibonacci function with memoization via functools.lru_cache. The cache stores prior results so each n is computed only once,
  giving O(n) time.

  from functools import lru_cache

  @lru_cache(maxsize=None)
  def fib(n: int) -> int:
      if n < 2:
          return n
      return fib(n - 1) + fib(n - 2)
