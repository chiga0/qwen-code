⏺ JavaScript Event Loop

  The event loop coordinates synchronous code, microtasks, and macrotasks.

  1. Run synchronous code on the call stack until empty.
  2. Drain all microtasks (Promises, queueMicrotask).
  3. Process one macrotask (setTimeout, I/O), then repeat.

  console.log('A');
  queueMicrotask(() => console.log('B'));
  setTimeout(() => console.log('C'), 0);
  console.log('D');
